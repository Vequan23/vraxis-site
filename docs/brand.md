# Vraxis identity

## Brand idea

Vraxis brings independent local tools into one coordinated system. The mark uses two paths that converge around a central axis. The outer V holds the system together without turning the products into one monolith.

## Primary assets

- `vraxis-mark.svg` is the default standalone mark.
- `vraxis-mark-mono.svg` is for one-color and small-format use.
- `vraxis-lockup.svg` pairs the mark with the name.
- `vraxis-app-icon.svg` is the starting point for app and social icons.

## Colors

| Name | Hex | Use |
|---|---|---|
| Midnight | `#08111B` | Deep backgrounds |
| Graphite | `#111820` | Page background |
| Axis navy | `#0B2547` | Primary mark structure |
| Signal blue | `#1687F8` | Active path and links |
| Flow cyan | `#42D9F0` | Reading and discovery |
| Proof green | `#1AD592` | Verified work and safe completion |
| Cloud | `#E8F0F5` | Primary text on dark surfaces |

## Usage

- Keep clear space around the mark equal to the width of its center axis.
- Use the full-color mark on neutral light or dark backgrounds.
- Use the monochrome mark when color reproduction is limited.
- Do not rotate, stretch, outline, or add shadows to the mark.
- Do not place the mark inside Apple hardware or imply Apple affiliation.
