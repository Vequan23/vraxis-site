# Your tools. Your agents. Your machine.

Vraxis is a family of local-first tools for reading, understanding, writing, and distributing technical work. One CLI installs and opens the system.

## Install the Vraxis command center

```bash
npm install -g @vraxis/cli
vraxis
```

## Four tools. Four jobs.

Each product owns one part of the work. The CLI connects them without merging their data or logic.

### Vraxis Read

Read PDFs, EPUBs, Markdown, and web articles with an agent that stays grounded in the source.

### Aperta

Build evidence that you understand a codebase before you change it.

### ArchNode

Turn engineering thought into connected RFCs, decisions, diagrams, and durable technical writing.

### Distribution-OS

Turn product evidence into reviewed distribution plans, drafts, and measurable work.

## Inspect what the products run on.

The runtime, interface system, desktop packager, and command center are separate packages with clear boundaries.

## Control is part of the product.

Your libraries, repositories, notes, and product evidence stay on your machine. Choose the model provider or local runtime that fits the job. See the sources, tools, approvals, and runtime behind important output. External actions wait for review.

## Start with one command.

Install the command center. Add only the tools you need.
